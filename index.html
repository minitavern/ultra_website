为角色扮演准备的能力

只保留产品里真正有的功能，不堆无关卖点。

  • 角色卡导入

    支持 PNG / JSON 角色卡，兼容 SillyTavern 常见规范；导入时可拆出世界书与正则。

  • BYOK 模型连接

    自备密钥直连主流 API；也可接 Ollama、LM Studio 等本地服务，密钥与请求路径由你掌控。

  • 世界书

    关键词激活、常驻条目、会话多选绑定，长剧情设定不轻易丢。

  • 正则脚本

    全局正则组与卡级脚本，prompt / 展示分相处理，对齐酒馆进阶玩法。

  • 互动卡面

    HTML / CSS 前端渲染与变量状态，适合带界面的互动角色卡。

  • 人设与备份

    多套 Persona；完整备份导出与恢复，换机可带走聊天与配置。

三步开始

有密钥就能聊；想跑本地模型也有专门教程。

  1. 1

    配置模型连接

    在设置里添加 API 连接并测试，或按教程搭建本地模型后再填入地址。

  2. 2

    导入或创建角色

    从文件导入角色卡，或手动填写角色信息后保存。

  3. 3

    开聊并按需进阶

    绑定世界书、正则与人设；需要时再开互动卡面与备份。
